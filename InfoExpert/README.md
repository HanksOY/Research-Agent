How to run appliction:
1. Open the folder "InfoExpert" with VS Code. Type "python agent.py dev" in the terminal 1
2. Open the folder "Interface" with VS Code. Type "pnpm dev" in the terminal 2.
If you can not run the code, please install dependencies fisrt with typing "pnpm install"
3. Open brower with this link "http://localhost:3000", hit "Connect"
